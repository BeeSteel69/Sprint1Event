# Sprint1Event

## Описание

Каркас приложения с минимальным набором функциональности при работе с событиями Event (CRUD операции)

## Что нужно знать перед началом

Для запуска проекта потребуется:
* .NET 9 SDK или более новая версия (https://dotnet.microsoft.com/download)
* Visual Studio 2022 или Visual Studio Code

## Как запустить

1. Клонируйте репозиторий `git clone https://github.com/BeeSteel69/Sprint1Event`
2. Перейдите в папку с проектом `src/EventService` (относительно корня репозитория).
3. Выполните команду (компиляция и запуск): dotnet run EventService.csproj

## Как использовать

Запустите swagger (http://localhost:5202/swagger/index.html) и выполните команды CRUD.
	  
## Примеры эндпоинтов API

## Эндпоинт: GET /api/events
**Описание:** Возвращает список всех событий.
**Метод:** GET
**Параметры пути (Path Params):** 
`title` (string,опциональный) — поиск по названию событию (регистронезависимый, частичное совпадение).
`from` (datetime,опциональный) — события, которые начинаются не раньше указанной даты
`to` (datetime,опциональный) — события, которые заканчиваются не позже указанной даты.
`page` (int,опциональный, c значением по умолчанию 1) —  Параметр пагинации - страница, которую необходимо вернуть.
`pageSize` (int,опциональный, со значением по умолчанию 10) — Параметр пагинации - количество элементов на странице.
**Пример ответа:**
```json
[
	{
	  "items": [
		{
		  "id": 1,
		  "title": "string1",
		  "description": "string1",
		  "startAt": "2026-11-17T20:13:14.186Z",
		  "endAt": "2026-11-18T20:13:14.187Z"
		}
	  ],
	  "totalCount": 1,
	  "page": 1,
	  "pageSize": 10,
	  "totalPages": 1
	}
]
```
**Ответы:**
  * `200 Ok` — Успешно возвращает события
  * `400 Bad Request` —  Невалидные данные
	{
	  "title": "Bad Request",
	  "status": 400,
	  "detail": "Номер страницы (page) должен быть >= 1",
	  "instance": "/api/Events"
	}

## Эндпоинт: GET /api/events/{id}
**Описание:** Возвращает событие по ID.
**Метод:** GET
**Параметры пути (Path Params):** `id` (int) — Уникальный идентификатор события.
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Ответы:**
  * `200 Ok` — Успешно возвращает событие по ID
  * `404 Not Found` —  Не найдено событие по ID
	{
	  "title": "Not Found",
	  "status": 404,
	  "detail": "Невозможно получить несуществующее событие",
	  "instance": "/api/Events/44"
	}
  
## Эндпоинт: POST /api/events
**Описание:** Создаёт новое событие.
**Метод:** POST
**Параметры пути (Path Params):** Без параметров
**Тело запроса (Body):**
```json
{
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Ответы:**
  * `201 Created` — Возвращает созданное событие с присвоенным ID.
  * `400 Bad Request` —  Невалидные данные
	{
	  "title": "Bad Request",
	  "status": 400,
	  "detail": "Дата окончания (EndAt) должна быть строго позже даты начала (StartAt)",
	  "instance": "/api/Events"
	}

```json
}
```
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event2",
  "description": "Desc2",
  "startAt": "2026-11-06T20:11:46.909Z",
  "endAt": "2026-11-15T20:11:46.909Z"
}
```
**Ответы:**
  * `200 Ok` — Успешное обновление события по ID.
  * `400 Bad Request` —  Невалидные данные
	{
	  "title": "Bad Request",
	  "status": 400,
	  "detail": "Дата окончания (EndAt) должна быть строго позже даты начала (StartAt)",

	}

## Эндпоинт: DELETE /api/events/{id}
**Описание:** Удаляет событие по ID
**Метод:** DELETE

**Ответы:**

  * `404 Not Found` —  Не найдено событие по ID
	{
	  "title": "Not Found",
	  "status": 404,
	  "detail": "Невозможно удалить несуществующее событие",
	  "instance": "/api/Events/22"
	}
