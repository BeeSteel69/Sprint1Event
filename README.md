# Sprint1Event

## Описание

Каркас приложения с минимальным набором функциональности при работе с событиями Event (CPUD операции)

## Что нужно знать перед началом

Для запуска проекта потребуется:
* .NET 9 SDK или более новая версия (https://dotnet.microsoft.com/download)
* Visual Studio 2022 или Visual Studio Code

## Как запустить

1. Клонируйте репозиторий `git clone https://github.com/BeeSteel69/Sprint1Event`
2. Перейдите в папку с проектом `src/EventService` (относительно корня репозитория).
3. Выполните команду (компиляция и запуск): dotnet run EventService.csproj

## Как использовать

Запустите swagger (http://localhost:5202/swagger/index.html) и выполните команды CPUD.
	  
## Примеры эндпойнтов API

## Эндпоинт: GET /api/events
**Описание:** Возвращает список всех событий.
**Метод:** GET
**Параметры пути (Path Params):** Без параметров
**Пример ответа:**
```json
[
  {
    "id": 1,
    "title": "Event1",
    "description": "Desc1",
    "startAt": "2026-11-06T19:52:49.319Z",
    "endAt": "2026-11-07T19:52:49.319Z"
  }
]
```
**Ответы:**
  * `200 Ok` — Успешно возвращает события

## Эндпоинт: GET /api/events/{id}
**Описание:** Возвращает событие по ID.
**Метод:** GET
**Параметры пути (Path Params):** `id` (int) — Уникальный идентификатор события.
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Ответы:**
  * `200 Ok` — Успешно возвращает событие по ID
  * `404 Not Found` —  Не найдено событие по ID
  
## Эндпоинт: POST /api/events
**Описание:** Создаёт новое событие.
**Метод:** POST
**Параметры пути (Path Params):** Без параметров
**Тело запроса (Body):**
```json
{
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event1",
  "description": "Desc1",
  "startAt": "2026-11-06T19:52:49.319Z",
  "endAt": "2026-11-07T19:52:49.319Z"
}
```
**Ответы:**
  * `201 Created` — Возвращает созданное событие с присвоенным ID.
  * `400 Bad Request` —  Невалидные данные

  
## Эндпоинт: PUT /api/events/{id}
**Описание:** Обновляет событие по ID
**Метод:** PUT
**Параметры пути (Path Params):** `id` (int) — Уникальный идентификатор события.
**Тело запроса (Body):**
```json
{
  "title": "Event2",
  "description": "Desc2",
  "startAt": "2026-11-06T20:11:46.909Z",
  "endAt": "2026-11-15T20:11:46.909Z"
}
```
**Пример ответа:**
```json
{
  "id": 1,
  "title": "Event2",
  "description": "Desc2",
  "startAt": "2026-11-06T20:11:46.909Z",
  "endAt": "2026-11-15T20:11:46.909Z"
}
```
**Ответы:**
  * `200 Ok` — Успешное обновление события по ID.
  * `400 Bad Request` —  Невалидные данные
  * `404 Not Found` —  Не найдено событие по ID
  * `500 Internal Server Error` —  Произошла внутренняя ошибка сервера.

## Эндпоинт: DELETE /api/events/{id}
**Описание:** Удаляет событие по ID
**Метод:** DELETE
**Параметры пути (Path Params):** `id` (int) — Уникальный идентификатор события.
**Ответы:**
  * `204 No Content` — Успешное удаление события по ID.
  * `404 Not Found` —  Не найдено событие по ID
